## 📂 About

Second-year IT undergraduate at NSUT (Delhi), specializing in **Geoinformatics** — building where spatial data meets machine learning.

**What I actually do:**
- **Deep learning on satellite data** — built CNN-based bathymetry models mapping river depths from Sentinel/Landsat imagery (TensorFlow, 80-90% accuracy), end-to-end ML pipelines for infrastructure site identification via GEE + QGIS
- **Agentic AI systems** — autonomous agents with planning, multi-agent architectures, RAG pipelines. Advanced prompt engineering for reliable AI applications
- **Quantitative analysis** — financial forecasting with scikit-learn/pandas at WorldQuant; systematic strategy backtesting

**Tools:** Python · TensorFlow · PyTorch · Google Earth Engine · QGIS · scikit-learn · LangChain

> Open to collaborations in geospatial AI, agentic systems, and applied ML research.
